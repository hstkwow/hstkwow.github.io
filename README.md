# HSTK · 个人网站

[访问网站](https://hstkwow.top/) · [项目](https://hstkwow.top/projects.html) · [博客](https://hstkwow.top/papers.html)

孙涛的个人网站，展示个人经历、项目、论文笔记与技术文章。

使用 **HTML、CSS、JavaScript 和 Python** 构建，由 **GitHub Actions** 自动发布到 **GitHub Pages**。

本仓库保存**构建后的网页与资源**。源码和 Markdown 原稿在私有仓库 `hstkwow-site-source` 中维护，请在源码仓库修改内容，这里的直接修改会被下次自动发布覆盖。

当前版本对应的源码提交见 [`build-info.json`](build-info.json)。
