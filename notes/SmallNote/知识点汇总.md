<a id="全色锐化评价指标"></a>

## 全色锐化评价指标

来源：[Text-guided Multimodal Fusion Network](../TMMFNet/index.md)

+ **峰值信噪比**(Peak Signal-Noise Ration)，融合图像与真实图像的像素差值，\(\mathrm{PSNR}=10\log_{10}\left(\frac{MAX^2}{\mathrm{MSE}}\right),\)越大越好。
   + **结构相似性指数**(Structural Similarity Index Measure)，形容亮度、对比度和局部结构的相似性，最大值为1
   + **光谱角映射**(Spectral Angle Mapper)，把一个像素在所有波段上的数值看成一个向量，比较融合结果与真实图像的向量夹角：\[ \mathrm{SAM} =\arccos\left( \frac{\hat{\mathbf s}\cdot\mathbf s} {\|\hat{\mathbf s}\|\,\|\mathbf s\|} \right) \] ，夹角越小越好。
   + **空间相关系数**(Spatial Correlation Coefficient)：用来衡量融合图像是否保留了真实图像的空间结构和细节，越接近 1 越好。
   + **相对全局合成误差**(Erreur Relative Globale Adimensionnelle de Synthèse)，衡量融合结果在各个波段上的数值误差，越小越好
   + **光谱失真指数**(Spectral Distortion Index)\(D_\lambda\) 原始 MS 各波段之间的关系”和“融合结果各波段之间的关系，越小越好
   + **空间失真指数**(Spatial Distortion Index)\(D_s\) 检查融合结果与 PAN 的空间结构关系是否合理，越小越好
   + **无参考质量评价指标**(Quality with No Reference) 把前两种失真结合，越大越好，还有混合QNR就是HQNR

<a id="深度展开"></a>

## 深度展开

来源：[UP-PAN](../UPPAN/index.md)

**深度展开**：将传统优化算法的有限次**迭代步骤**逐步展开为**神经网络的层**或模块，并把其中部分参数或运算设计成可学习的形式，再通过数据端到端训练。

<a id="卷积字典滤波器filter"></a>

## 卷积字典/滤波器(filter)

来源：[UP-PAN](../UPPAN/index.md)

**卷积字典/滤波器(filter)**：一组**固定或可学习**的权重，用来对输入信号的局部邻域进行加权计算，从而提取或改变某些信息

<a id="贝叶斯公式"></a>

## 贝叶斯公式

来源：[UP-PAN](../UPPAN/index.md)

**贝叶斯公式**：基本形式\(P(Y|X)=\frac{P(X|Y)P(Y)}{P(X)}\) ，公式是由条件概率推导出来\(P(A|B)=\frac{P(A\cap B)}{P(B)}\),\(P(B|A)=\frac{P(A\cap B)}{P(A)}\),故由\(P(A\cap B)=P(A|B)P(B)=P(B|A)P(A)\),故\(P(A|B)=\frac{P(B|A)P(A)}{P(B)}\),

<a id="最大后验"></a>

## 最大后验

来源：[UP-PAN](../UPPAN/index.md)

**最大后验**：\(\hat Z_{MAP}=\arg\max_Z P(Z\mid X,Y)\)，arg是argument，表示找出那个输入值让函数达到最大，\(P(Z|X,Y)=\frac{P(X,Y|Z)P(Z)}{P(X,Y)}\)，若X，Y相互独立则\(P(X,Y|Z)=P(X|Z)P(Y|Z)，P(X|Y)\)是已经观测到的，其值已定。故\(P(Z|X,Y) \propto P(X|Z)P(Y|Z)P(Z)\)

<a id="先验项prior"></a>

## 先验项

来源：[UP-PAN](../UPPAN/index.md)

**先验项**（Prior）：结果本身有多少可能，例如上式中的P(Z)。**似然项**（Likelihoood）：这个结果能多好的解释条件（观测），例如上式中的P(X,Y|Z)。**后验项**（Posterior）:给定条件（观测），出现这个结果的可能

<a id="观测模型"></a>

## 观测模型

来源：[UP-PAN](../UPPAN/index.md)

**观测模型**：也就是模拟图像得到的过程，会有图像退化，还有噪声的干扰。也就是模拟传感器采集图像的过程。对退化得到的图像叫做观测。

<a id="正则化项"></a>

## 正则化项

来源：[UP-PAN](../UPPAN/index.md)

**正则化项**：加入优化目标或损失函数中的**额外惩罚项**，用来表达对模型参数或重建结果的偏好，引导求解得到符合先验的合理结果。

<a id="半二次分裂方法"></a>

## 半二次分裂方法

来源：[UP-PAN](../UPPAN/index.md)

**半二次分裂方法**(Half-Quadratic Splitting)：是一种通过引入**辅助变量**，并加入**二次一致性惩罚**，将复杂优化问题拆成多个较易求解的子问题，再交替求解的优化方法。

<a id="近端梯度下降"></a>

## 近端梯度下降

来源：[UP-PAN](../UPPAN/index.md)

**近端梯度下降**(Proximal Gradient Descent)：是一种求解“**可微函数与正则化函数之和”**的迭代优化算法：每次先对可微部分进行梯度下降，再通过**近端映射**（近端算子）处理正则化部分。

<a id="向量量化"></a>

## 向量量化

来源：[UP-PAN](../UPPAN/index.md)

**向量量化：**是把一个连续取值的向量，映射为有限码本中某个代表向量的过程，通常选择距离最近的那个。

<a id="wald协议"></a>

## Wald协议

来源：[UP-PAN](../UPPAN/index.md)

**Wald协议：**通过将原始 MS 和 PAN 同比例降采样，构造一个低一级分辨率的全色锐化任务，并把原始 MS 作为参考真值，用于训练和评价融合结果。这样就解决了真实高分辨率 MS 参考图像难以获得的问题。

## 高频与低频信息

高频信息就是像素变化快的地方，例如边缘、细节、噪声，低频信息就是像素变化慢。

<a id="swin-transformer-窗口注意力"></a>

## Swin Transformer 窗口注意力

来源：[Dual-scale Attention Network](../DANet/index.md)

Swin Transformer：改进普通transfomer的注意力计算（计算与全部token注意力），改为划分窗口，在窗口内token互相计算注意力，然后移动窗口。缺点是远距离信息传播较慢。
